# Files for AI Review

This folder contains supplemental text exports used to inspect the reporting engine's Access objects and architecture.

The `vba` folder contains the primary exported VBA modules.

Files in this folder may include supporting object definitions, query exports, form code, table structures, or review-oriented copies that provide additional context.

When duplicate module names exist, treat the version in the parent `vba` folder as authoritative unless a file in this folder is explicitly marked as newer.
